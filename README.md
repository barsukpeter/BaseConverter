# Перетворювач систем числення
Програма переводить ціле невід'ємне число з однієї системи числення в іншу. 
Вхід: число, вихідна й цільова основа (від 2 до 16) через пробіл. 
Вихід: запис числа в цільовій системі, цифри 10-15 позначаються літерами A-F.

## Як зібрати
- відкрити файл LR1GIT.slnx у Visual Studio 2026;
- обрати конфігурацію Debug і платформу x64;
- виконати Збірка -> Зібрати рішення (Ctrl+Shift+B).

## Як запустити
Запустити без налагодження (Ctrl+F5).

## Приклад роботи
```
Введіть число, вихідну й цільову основу через пробіл: 255 10 16
FF
```

## Що програма не приймає
- порожній рядок;
- кількість значень, відмінну від трьох;
- основу менше 2 або більше 16;
- цифру, недопустиму для вихідної основи (наприклад, 9 в основі 8);
- число, що не вміщується в 64 біти.
